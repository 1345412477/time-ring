# 时间圆环 Time Ring

一个用环形时钟可视化一天 24 小时的单页时间规划工具。右侧清单录入事项，左侧圆环按类别用颜色渲染时间段，未安排的时间默认浅绿色——帮你一眼看清时间花在哪、休息了多久。

## 在线体验

部署完成后访问：`https://1345412477.github.io/time-ring/`

## 功能

- **24 小时环形时钟**：标准 12 小时表盘，右上角切换上午 / 下午，实时走时指针
- **事项清单**：右侧添加、编辑、删除事项，支持时间段、类别、备注
- **类别配色**：空闲（浅绿）、睡眠（深绿）、工作（浅蓝）、学习（薄荷）、运动（浅黄）、娱乐（浅粉）
- **当日统计**：底部自动汇总各类别占用时长
- **进行中提示**：圆心下方显示当前正在进行的事项
- **数据导出**：一键导出当日 JSON
- **本地存储**：数据保存在浏览器 localStorage，按日期分键，不上云

## 技术栈

- 原生 HTML / CSS / JavaScript，无框架、无构建
- SVG 绘制圆环与刻度
- GitHub Actions 自动部署到 GitHub Pages

## 本地运行

直接用浏览器打开 `index.html` 即可，无需任何依赖。
